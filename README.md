# Uchinoko for Palworld 非公式改変版

VRMアバターをPalworldのプレイヤー用MODへ変換するWindows向けツールです。
Uchinoko 2.2.13を基に、複数アバター運用と防具単位の切り替えに対応する独自改修を加えています。

> [!IMPORTANT]
> この配布物は非公式改変版です。元作者および元リポジトリの公式サポート対象ではありません。
> 本改変版の問題を元作者へ報告しないでください。問題報告は本リポジトリの[GitHub Issues](https://github.com/G-Orpheus/Uchinoko-OutputScale-OutfitSelector/issues)へお願いします。

## 主な改変機能

- VRMモデルの出力倍率を設定可能（既定値 `1.00`）
- 上書きする防具を実アセット単位で個別選択
- 防具一覧の検索、すべて選択、すべて解除
- 選択した防具だけを収録する部分選択PAK
- アバターごとに固有のMaterial Instance・Textureパスを生成
- Base ColorのAlpha保持とMasked表示
- 中立Normal / ORM（Metallic 0、Roughness 0.8、Specular 0、AO 1）
- 作成済みMODの出力フォルダをエクスプローラーで開く機能
- 作成済みMODのチェック選択と、競合しない複数MODの手動一括適用
- 旧 `job.json` を全防具選択として読み込む後方互換性

## 導入

1. ZIPを任意のフォルダへ展開します。
2. `Uchinoko.exe`を起動します。
3. 初回起動時はBlender 4.3.2が自動導入されるため、完了まで待ちます。

既存のUchinokoや別バージョンへ上書きせず、**この非公式改変版専用の新しいフォルダへ展開することを推奨**します。旧版の中間生成物や設定が混在すると、意図しない変換結果になる可能性があります。

## 基本的な使い方

1. VRMファイルを画面へドラッグ＆ドロップするか、アバター選択から指定します。
2. 必要に応じて「こだわり設定」を開きます。
3. 「出力倍率」と「上書きする防具」を設定します。
4. 「フル変換」を実行します。
5. 作成済みMOD一覧で使用するMODをチェックし、「チェックしたMODを適用」を押します。Palworldへの反映は必ず手動で行います。

詳しい操作は `manual.md` を参照してください。

## 防具ごとの複数VRM運用

異なる防具を対象にした複数のVRM MODを作成・同時適用すると、ゲーム内で装備する防具に応じてVRMアバターを切り替えられます。

例:

- VRM Aは防具Aだけを選択
- VRM Bは防具Bだけを選択
- 防具Aを装備するとVRM A、防具Bを装備するとVRM Bを表示

同じ防具を複数のMODで上書きすると競合します。Uchinokoは適用前に防具の重複を検査し、競合があればPAKのコピーを開始せず中止します。複数MODでは上書き対象が重ならないように選択してください。

Uchinoko製MODの適用中はプレイヤー本来のヘッドメッシュが非表示になります。どのMODにも割り当てていない防具を装備すると頭部が表示されません。使用する防具はいずれか1つのMODへ割り当ててください。元の状態へ戻す場合は、全MODのチェックを外して適用ボタンを押します。

## 対象範囲

- 防具選択の対象は、現在のPalworld対応データと変換パイプラインが対応する非コラボ防具58件です。
- コラボ防具（Yakushima、Octaviaなど）は対象外で、PAKにも収録しません。
- 頭、髪、頭装備は現行パイプラインの共通変換対象です。
- 他のPAK MODと同じアセットを変更する場合は競合する可能性があります。

## Unity / FBX入力

VRM直接入力に加えて、Unity 2022.3系のプロジェクト内Prefabと、Humanoid対応表を用意したFBX入力を維持しています。通常はVRM直接入力が簡単です。詳しくは `manual.md` を参照してください。
