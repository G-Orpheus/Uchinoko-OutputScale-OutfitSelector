# Privacy Policy

Last updated: August 1, 2026

The unofficial modified edition of Uchinoko for Palworld performs normal conversion work entirely on the user's local computer. It does not transmit VRM files, generated textures, generated PAK files, or Palworld save data to any external service.

The application has no in-app report submission feature and does not transmit diagnostics or files. It does not send information to the original developer's report service, does not access the original developer's update-check server, and provides neither update notifications nor automatic updates. The “Copy Diagnostic Log” button only copies redacted text to the Windows clipboard.

## External network access

Only when Blender 4.3.2 has not yet been installed, first-time setup may access:

- Source: `https://download.blender.org/release/Blender4.3/blender-4.3.2-windows-x64.zip`
- Purpose: install Blender, which is required for VRM conversion
- Storage: `assets\tools\blender-4.3.2-windows-x64\` under the extracted application folder

The download is checked against a pinned SHA-256 value. No mirror operated by the original developer is used. If the user supplies an offline source ZIP, no download is performed.

## Unofficial edition

This is an unofficial modified edition and is not supported by the original developer. Do not ask the original developer for help with this edition. Report problems through the [modified edition's GitHub Issues](https://github.com/Guldin-Orpheus/Uchinoko-OutputScale-OutfitSelector/issues). Review logs for personal information before posting them publicly.
